# 공단 로그인 사용설명서

근로복지공단 토탈서비스·국민연금 EDI·건강보험 EDI·효성CMS에 **공동인증서로 로그인해 주는 윈도우 프로그램**입니다.
키를 누르면 그 계정 전용 크롬 창이 열리고 로그인까지 진행합니다. 신고·제출은 하지 않습니다.

---

## 1. 설치 전에 준비할 것

| 항목 | 확인 방법 |
|---|---|
| Windows 10/11 64비트 | 설정 → 시스템 → 정보 |
| **구글 크롬** | 크롬이 없으면 창이 열리지 않습니다. 엣지·웨일은 지원하지 않습니다 |
| **공동인증서 파일** | 하드디스크(`C:\Users\<사용자>\AppData\LocalLow\NPKI`) 또는 USB. 폴더 안에 `signCert.der`·`signPri.key` 가 있어야 합니다 |
| 사이트별 보안프로그램 | 건강보험 EDI·효성CMS = **AnySign4PC**. 해당 사이트에 크롬으로 한 번 접속해 안내대로 설치해 두세요 |

**쓸 수 없는 인증서** — 금융인증서(클라우드), 보안토큰(HSM), 휴대폰 인증서 보관. 파일(`NPKI`) 형태의 공동인증서만 됩니다.

## 2. 설치

1. [Releases](https://github.com/seojaehong/gov-cert-login/releases/latest)에서 `GovLogin_setup_<버전>.exe` 를 받아 실행합니다. 관리자 권한은 필요 없습니다.
2. 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**을 누릅니다(코드 서명 전이라 뜹니다).
3. 백신이 막으면 「허용」 또는 예외 등록을 합니다. 이 프로그램은 크롬을 원격 조작하고 키 입력을 흉내 내기 때문에 백신이 의심할 수 있습니다.
4. 바탕화면의 **「공단 로그인」**을 엽니다.

## 3. 처음 설정 (계정 등록)

처음 열면 설정 화면이 뜹니다.

1. **계정 이름** — 알아보기 쉬운 이름(예: 사무소, 대리인1)
2. **인증서 고르기** — PC의 `NPKI` 폴더 인증서가 목록에 나옵니다. USB나 다른 폴더에 있으면 「인증서 폴더 지정」으로 그 폴더를 고릅니다
3. **인증서 비밀번호** 입력
4. **쓸 사이트 체크** — 사이트마다 추가로 묻는 값이 있습니다

| 사이트 | 추가 입력 |
|---|---|
| 근로복지공단 토탈서비스 | (개인 탭 사용 시) 주민등록번호 |
| 국민연금 EDI | (선택) EDI 사업장 비밀번호 |
| 건강보험 EDI | 없음. 단 비밀번호는 **화면 보안 키패드로 직접** 누릅니다 |
| 효성CMS | 사업자등록번호 |

5. **저장**. 계정이 여러 개면 같은 방법으로 더 추가합니다. 키는 「계정 × 사이트」마다 하나씩 생깁니다.

## 4. 매일 쓰는 법

- **키 하나 누르기** → 그 계정·사이트 크롬 창이 열리고 로그인됩니다(사이트에 따라 20초~1분).
- **전체 열기** / 계정별 **모두 열기** — 여러 창을 한 번에.
- **숫자 키 조합** — `1` `4` 처럼 잇달아 누르면 그 키들을 함께 엽니다. `0` = 전체.
- 키의 **불** — 6초마다 로그인 상태를 확인해 켭니다. 꺼지면 로그아웃·창 닫힘입니다.
- 계정마다 크롬 프로필이 따로라 **서로 로그인을 끊지 않습니다.** 평소 쓰는 크롬과도 섞이지 않습니다.
- 창은 직접 닫으면 됩니다. 남은 크롬이 있으면 다음에 열 때 그 계정 크롬만 정리합니다.

### 처음 한 번만 하는 일

토탈서비스·효성CMS 첫 로그인 때 인증서를 그 계정 크롬의 **브라우저 저장소**에 넣습니다(「브라우저에 저장」).
다음부터는 목록에서 바로 고릅니다. 인증서는 인증서 비밀번호로 암호화된 채 저장됩니다.

## 5. 비밀번호·개인정보는 어디에

- 인증서 비밀번호·주민등록번호·EDI 사업장 비밀번호 → **윈도우 보안 저장소(DPAPI)** 로 암호화해
  `%LOCALAPPDATA%\gov-cert-login\secrets.json` 에 둡니다. **이 PC·이 윈도우 계정에서만** 풀립니다.
- **다른 PC로 옮겨지지 않습니다.** 새 PC에서는 설정을 다시 합니다(파일을 복사해도 풀리지 않습니다).
- 서버로 보내지 않습니다. 화면·기록에는 「저장됨」 여부만 남습니다.

## 6. 공용 PC에서 쓰지 마세요

로그인된 창은 다른 프로그램이 붙어 쓸 수 있도록 PC 안쪽 포트(`127.0.0.1:94xx`)를 열어 둡니다.
**같은 PC의 다른 프로그램은 로그인된 공단 화면을 조작할 수 있습니다.**
본인만 쓰는 업무 PC에서 쓰고, 다 쓰면 창을 닫으세요. 여러 사람이 로그인해 쓰는 PC·원격 접속 PC에서는 쓰지 마세요.

## 7. 안 될 때

먼저 **기록**을 봅니다 — `%LOCALAPPDATA%\gov-cert-login\logs`

| 파일 | 내용 |
|---|---|
| `last_<키>.txt` | 마지막 결과 한 줄 |
| `run_<키>_<시각>.log` | 실행 전체 기록. 「⚠」 줄이 원인 |
| `fail_<키>_<시각>.png` | 실패 때 화면(업무 화면이 찍힐 수 있으니 공유 주의) |

| 증상 | 조치 |
|---|---|
| 창이 아예 안 열림 | 크롬 설치 확인. 런처가 이미 떠 있는지(작업표시줄) 확인 |
| 인증서 목록이 비어 있음 | 「인증서 폴더 지정」으로 `NPKI` 폴더 또는 USB 폴더 지정 |
| 「인증서 암호가 틀렸습니다」 | 설정에서 비밀번호 다시 저장. 5회 틀리면 인증서가 잠길 수 있으니 반복하지 마세요 |
| 건보·효성 「AnySign for PC 설치가 필요」 반복 | ①트레이의 AnySign 종료 후 사이트 안내대로 재설치 ②다른 기관 사이트가 포트를 바꾼 경우 → 관리자 PowerShell에서 `tools\install_anysign_guard.ps1`(README 참고) |
| 건보 비밀번호가 안 들어감 | 정상입니다. 화면 보안 키패드로 직접 누르세요(5분 기다립니다) |
| 사이트 화면이 바뀐 뒤 멈춤 | 공단 화면 개편 때 생깁니다. 새 버전을 기다리세요 |
| 위쪽에 「새 버전」 단추 | 눌러서 새 설치 파일을 받아 설치합니다(설정·비밀번호는 유지) |

## 8. 지우기

설정 → 앱 → 「공단 로그인」 제거. 설정·비밀번호·크롬 프로필은 `%LOCALAPPDATA%\gov-cert-login` 과
`%LOCALAPPDATA%\gov-cert-login-profile-*` 폴더에 남으니, 완전히 지우려면 이 폴더들도 삭제하세요.

## 9. 알아 둘 것

- 각 공단·효성과 관계없는 개인 도구입니다. 사이트 개편 시 자동 로그인이 멈출 수 있습니다.
- 본인(또는 소속 사무소)의 인증서로 본인 계정에 로그인하는 용도로만 쓰세요.
- 보안 키패드·키보드보안 프로그램을 우회하지 않습니다.
